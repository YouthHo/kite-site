### 改动
- `.github/workflows/` 新增 3 条工作流，均监听 `master`/`main` push + workflow_dispatch
  - Vercel / Cloudflare 工作流带 guard step：secrets 缺失时优雅跳过，不让 CI 变红

- `vite.config.js`：`base` 改为读 `process.env.VITE_BASE`（默认 `/`），新增两个构建期插件
  - `spa-fallback-404`：复制 index.html → 404.html，解决 GH Pages 无 rewrite 的深链接 404
  - `rewrite-data-asset-base`：改写 `src/data/*.json` 中硬编码的 `"/images/` 前缀（141 处），
    仅在 base !== '/' 时生效。**这是子路径部署最大的坑**，Vue 模板里的 `<img src>` Vite 会自动处理，
    但 JSON 里的纯字符串不会。
- `scripts/build-gh.cjs` + `npm run build:gh`：跨平台注入 base，本地复现 Pages 构建
- `public/_headers`（Cloudflare/Netlify 缓存）、`public/.nojekyll`、根目录 `DEPLOY.md`

### 环境注意事项
- **vite build 清空 dist 会被沙箱 safe-delete 拦截**（trash 操作失败）。
  规避：构建前先 `rm -rf dist`（需 sandbox 放行）或把 dist 改名移开。
- 本机 `credential.helper=helper-selector`，无 tty 时必然失败；Windows 凭据管理器里
  也没有 github 凭据，`gh` CLI 未安装。推送需用户自行处理或提供 PAT（须含 `workflow` scope）。
