## Thesis

1949 前后的中国谍战，属于水墨、印章、宣纸的文化语境。把「间谍档案」从西式暗色皮换成**东方水墨 + 朱砂印泥 + 宣纸**的当代演绎：墨夜为底、朱砂为魂、一线风筝贯穿全站。

## 字体声线

- 展示级：Noto Serif SC 重活字（700）+ 负字距 + 墨晕 text-shadow，`--fs-display` 用于首屏巨字。
- 情报/档案注脚：JetBrains Mono 低存在感（降字号/降对比），不抢主角。
- 正文：Noto Sans SC 舒适行高，保留档案阅读的克制动。

## 贯穿母题「一线风筝」

一条**朱砂笔触风筝线**（SVG 路径复用）贯穿：首屏被一笔牵出 → 图谱关系连线 → 分隔线 → 进度条 → 光标拖尾。全站视觉 IP。

## 动效语法

`墨晕开`(ink bleed) / `封印落定`(seal stamp) / `卷轴展开`(scroll unfurl) / `一线牵引`(thread draw) 四类原创动效，全部经 motion.js 封装 + reduced-motion 静态等价。

## 纹理隐喻

宣纸纤维 + 淡墨点（InkTexture/PaperGrain）替代 FilmGrain/ScanLine 的「老电影」语义。
