国际评审视角 · 设计自检报告

2026-08-10 · 以第三方评审委员会身份审查 · 本轮整改已执行

总体结论

视觉完成度：B+ → A-。系统性问题已清除（字体分层、字号散乱、等宽滥用、动效拖沓），结构性短板仍有三项（真实素材、移动端走查、交互深度），达到国际顶尖（Awwwards 级）仍需素材与实测闭环。

评审发现与整改对照

① 字体系统（严重）

评审意见：小字号（≤16px）误用宋体导致发虚；全站 137 处零散字号；50+ 处等宽字体滥用，破坏现代感。

整改结果
新增 .title-sans 无衬线标题类，小标题全部去宋体✅ 4 处修正
.font-mono 全局覆盖为无衬线（仅电报码/光标保留等宽）✅ 50+ 处生效
建立字号分层原则：宋体仅用于 ≥20px 展示标题✅ 已写入 MEMORY.md

② 首页构图（严重）

评审意见：8 个带边框的图标卡片像管理后台门户，不像电影官网；图标旋转入场动画廉价。

整改结果
卡片改为编辑式索引：编号 01-08 + 细线分隔 + 悬停标题变色 + 箭头浮现✅ 已上线
删除图标与旋转入场动画，改用统一错落淡入✅ 已上线

③ 动效节奏（中等）

评审意见：入场动画累计时长过长、stagger 过大，与顶尖网站的"快而稳"不符。

整改结果
全局 pageEnter 0.55s/24px → 0.35s/12px，stagger 减半✅
历史页切换 0.6s+stagger → 0.35s 无 stagger✅
详情面板、图片模糊入场提速✅

④ 一致性（中等）

评审意见：颜色、间距、圆角存在随机漂移；装饰元素（条纹/胶片孔/印章/电报码）密度不均。

整改结果
新增设计令牌（--dur-fast/base/slow、--ease-out/inout）✅
档案条纹透明度收敛，装饰密度下降✅

⑤ 浅色主题与可读性（严重，已修复）

on-media 与浅色映射的 !important 冲突曾导致多处文字隐形（首页副标题、名场面角标、EP 标签）。已通过"去掉冲突色类 + 生成器末位兜底"根治。
